# Command reference

| Command | Purpose |
|---|---|
| `architecture init` | Create policy and empty exception store |
| `architecture discover` | Build current architecture map |
| `architecture baseline` | Record reviewed existing findings |
| `architecture diff` | Compare current map to baseline |
| `architecture check` | Produce conformance report |
| `architecture reuse` | Search existing capabilities |
| `architecture contract init/show/validate/close` | Manage short-lived task scope |
| `architecture exception add/list/revoke` | Manage scoped expiring exceptions |
| `architecture policy validate` | Validate policy structure |
| `architecture doctor` | Validate all project-local architecture state |
