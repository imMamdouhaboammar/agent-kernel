# Agent Kernel Brand V2

## Core idea
Agent Kernel is not another agent. It is the small local layer that remembers repo rules, failure lessons, approval boundaries, and agent instructions.

The mark should feel like a kernel cell: local boundary, routing nodes, and one approved memory core.

## Visual direction
Dark terminal base, thin grey lines, off-white text, and one acid-yellow signal color.

Do not use heavy gradients, 3D shadows, oversized icons, or decorative AI visuals.

## Palette
- Black: `#050505`
- Panel: `#0B0B0B`
- Line: `#2A2A2A`
- Text: `#F4F4F1`
- Muted: `#8E8E88`
- Acid signal: `#F8F46A`
- Dim node: `#A6A6A0`

## Typography
Use JetBrains Mono for the mark lockup, README hero, CLI snippets, badges, and technical UI blocks.
Use thin to medium weights. Avoid bold-heavy headings unless the layout needs one focal line.

## Logo system
- Mark: pixel-boundary icon for avatar, favicon, npm, README top.
- Wordmark: mark plus “Agent Kernel”. “Kernel” can use acid yellow.
- README lockup: dark panel with compact command strip.

## README tone
Use compact product language:

“Local memory and safety for the AI coding agents you already use.”

Avoid vague AI language. Keep claims concrete: local files, safe-link, approvals, failure lessons, shared context.
