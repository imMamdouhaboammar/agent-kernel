ARCHITECTURE & GOVERNANCE

Built for the multi-agent reality.

Agent Kernel provides local-first memory, environment security, and architecture guardrails so agents never lose context or repeat old mistakes.

🔐

Project Environment Vault (`agent-kernel env`)

Automatically backs up local .env files with 0600 permissions using deterministic SHA256 project fingerprinting (Git Remote / commit hash). Auto-syncs on edits and auto-restores on fresh clones upon session start.

agent-kernel env link
agent-kernel env status
🧠

Universal Agent Skill Engine (`agent-kernel skills`)

18 pre-packaged, standardized Skill Modules automatically deployed across all AI agent environments (~/.claude/skills, ~/.codex/skills, ~/.gemini/config/skills, ~/.agents/skills).

agent-kernel skills sync
agent-kernel skills list
⚙️

Self-Evolve & Self-Learning Engine (`agent-kernel evolve`)

Captures session execution traces and user corrections (like /learn), synthesizing multi-step workflows into versioned Playbooks. Automatically registers universal hooks across Antigravity, Claude, Codex, and OpenCode.

agent-kernel evolve hooks
agent-kernel evolve list
