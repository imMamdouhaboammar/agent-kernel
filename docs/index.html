01 · the failure mode

Each new agent session restarts
with zero of your context.

You paste the same standards into every prompt. The same build error gets solved twice. An agent quietly rewrites a rule and you don't notice for a week. None of that is necessary.

memory

One folder of JSON. Six targets.

Rules, preferences, workflows, Failure Lessons, and project notes live at ~/.agent-kernel/source/. Compile emits per-agent files. No SaaS, no sync, no telemetry.

approval

Agents propose. You approve.

An agent can capture a failure or propose a rule — that lands in inbox/pending. Nothing reaches dist/ until you run ak approve. Hooks never publish.

failure lessons

Build error #247 won't repeat.

When npm test fails with the same signature twice, the kernel dedupes by project + command + error and tracks occurrences. Promote it once into a rule.

02 · operating model

Evidence in. Pending in.
Approved in. Compiled out.

  1. 01

    Capture

    A Claude hook or ak failure capture records the failure evidence — command, exit code, output excerpt, fix recipe.

  2. 02

    Propose

    Promotion creates a pending record in inbox/pending. The agent cannot approve its own work.

  3. 03

    Approve

    You run ak inbox, read the diff, then ak approve <id> --publish.

  4. 04

    Compile

    The kernel regenerates CLAUDE.md, AGENTS.md, Cursor rules, Gemini guidance. Next agent inherits.

built-in guards
  • rm -rf / · / · recursive chmod 777
  • curl | sh · piped installers
  • force push to default branch
  • secret patterns (API keys, tokens)
  • untracked .env at commit time

Hooks capture. Critical rules back by permissions, guards, and CI — not vibes.

03 · install

Two commands. Done.

Node 18.18+. Works on macOS, Linux, Windows. The kernel stores everything under ~/.agent-kernel and compiles in milliseconds.

01 — install
$ npm install -g @mamdouh-aboammar/agent-kernel
$ agent-kernel --version
0.7.2
02 — adopt in a project
$ cd ~/Projects/your-app
$ agent-kernel init --sync --enforce
$ agent-kernel-safe-link .
$ agent-kernel-safe-git-hook .
$ agent-kernel doctor

Already have hand-written AGENTS.md / CLAUDE.md? Run with --dry-run first. Safe-link writes only inside marked blocks and leaves your existing files intact.

04 · agent coverage

One compile. Six outputs.

The kernel doesn't fork your memory per agent. It compiles the same approved JSON into each agent's native format. Add a memory item once — every agent sees it next run.
